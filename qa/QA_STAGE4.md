# QA Етап 4 — Статистика (графіки)

Автотести: `pytest tests/test_qa_stage4.py -v`

## Сідові дані для тесту

```powershell
cd eventbot
python scripts/seed_stage4_events.py <твій_telegram_id>
```

`telegram_id` — з @userinfobot (той самий, що в `ADMIN_IDS`).

Додає **22 події** за останні ~30 днів + 2 майбутні (різні години та дні тижня).

| ID | Крок | Очікуваний результат | ✓ |
|----|------|----------------------|---|
| S4-01 | Без подій → «Статистика» → «Тиждень» | «Немає подій за тиждень» | ☐ |
| S4-02 | Запустити seed → «Тиждень» | PNG: 3 графіки, видно стовпчики | ☐ |
| S4-03 | «Місяць» | Графік за 30 днів, більше точок | ☐ |

**Pass:** усі 3.

**Прибрати сід:** Налаштування → Видалити всі події.
