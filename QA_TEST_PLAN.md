## User Stories

### Користувач (звичайний)


| ID    | Story                                                                                            | Критерій прийняття                              |
| ----- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| US-01 | Як користувач, я хочу запустити бота через `/start`, щоб зареєструватися і побачити головне меню | Привітання з ім'ям, 7 кнопок меню (вкл. Налаштування) |
| US-02 | Як користувач, я хочу створити подію з назвою, датою, часом і описом                             | Подія зберігається, показується підсумок        |
| US-03 | Як користувач, я хочу пропустити час і опис при створенні                                        | Подія створюється без часу/опису                |
| US-04 | Як користувач, я хочу додати нагадування (10 хв / 1 год / 1 день / власний час)                  | Бот підтверджує тип нагадування                 |
| US-05 | Як користувач, я хочу отримати автоматичне нагадування в Telegram                                | Повідомлення приходить у встановлений час       |
| US-06 | Як користувач, я хочу переглянути події на сьогодні, тиждень і всі майбутні                      | Список відображається або «подій немає»         |
| US-07 | Як користувач, я хочу змінити дату/час існуючої події                                            | Подія оновлюється, старі нагадування скидаються |
| US-08 | Як користувач, я хочу видалити подію з підтвердженням                                            | Подія і нагадування видаляються                 |
| US-09 | Як користувач, я хочу отримати довідку через `/help` або кнопку                                  | Список команд і можливостей                     |
| US-10 | Як користувач, я хочу використовувати команди `/today`, `/week`, `/all`                          | Той самий результат, що й через меню            |

## Передумови (Setup)


| #    | Крок                                                           | Статус |
| ---- | -------------------------------------------------------------- | ------ |
| P-01 | Python 3.11+ встановлено                                       | ☐      |
| P-02 | `pip install -r requirements.txt` виконано                     | ☐      |
| P-03 | У `.env` вказано валідний `BOT_TOKEN`                          | ☐      |
| P-04 | У `.env` вказано свій `ADMIN_IDS` (через @userinfobot)         | ☐      |
| P-05 | Бот запущено: `python main.py`                                 | ☐      |
| P-06 | У консолі: «База даних ініціалізована», «EventBot запущено»    | ☐      |
| P-07 | Є другий Telegram-акаунт (для перевірки ізоляції даних) — опц. | ☐      |


**Тестові дані для нагадувань:**

- Подія A: сьогодні + через 15 хв, нагадування «за 10 хв» → очікуй повідомлення через ~5 хв
- Подія B: сьогодні + через 12 хв, нагадування custom «2 хв» → очікуй через ~10 хв
- Подія C: завтра, нагадування «за 1 день» → очікуй сьогодні о 9:00 (якщо без часу) або за 24 год до події
